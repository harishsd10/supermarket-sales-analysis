# 🛒 Supermarket Sales Analytics & Supervised Machine Learning Intelligence Platform

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/harishsd10/supermarket-sales-analysis)

A comprehensive Data Science and Machine Learning platform analyzing retail transactions across 3 major supermarket branches in Myanmar.

## 🚀 Live Demo & Deployment
- **Deploy to Render:** Click the button above to launch on Render free tier.
- **Interactive Dashboard:** Complete HTML5 + Tailwind + Chart.js dynamic analytics platform with real-time demographic filters and live satisfaction prediction simulator.

## 📊 Core Features
1. **Sales & Category Trends:** Detailed revenue analysis across Food & Beverages, Sports & Travel, Electronic Accessories, Fashion, Home, and Health.
2. **Customer Behavior Study:** Gender & membership segmentation, Average Order Value (AOV), and payment method utilization.
3. **Supervised ML Classification:**
   - **Decision Tree Classifier** vs. **Logistic Regression** predicting customer rating categories (High: >= 7.0 vs. Low: < 7.0).
   - Accuracy, Precision, Recall, F1-Score, and ROC-AUC benchmarking.
4. **Actionable Recommendations:** Strategic business insights for operational parity, digital payment migration, and VIP member retention.

## 📦 Project Structure
- `index.html` — Interactive web analytics dashboard
- `supermarket_sales_ml.py` — Python pipeline script
- `Supermarket_Sales_Analysis_and_ML.ipynb` — Google Colab / Jupyter notebook
- `supermarket_sales.csv` — Raw Kaggle transactional dataset (1,000 records)
- `processed_supermarket_data.csv` — Feature-engineered dataset
- `executive_summary_report.md` — Strategic business recommendations report
- `render.yaml` & `Procfile` — Render cloud deployment configuration
